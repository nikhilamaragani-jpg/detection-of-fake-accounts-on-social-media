# Contributing

## Setup

```bash
pip install -r requirements.txt
python src/main.py
```

## Modules

- `preprocess.py` — load/clean/split
- `model.py` — train/evaluate/predict
- `database.py` — SQLite audit log
- `data/sample_social_accounts.csv` — demo dataset
